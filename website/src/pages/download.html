Install guide

Three steps to the valley

  1. Install the launcher

    Run the Windows installer, open the macOS disk image and drag the launcher into Applications, or mark the Linux AppImage as executable and run it.

  2. Sign in and update

    Create an account or sign in. The launcher then downloads the game files, checks every file against a checksum, and resumes if your connection drops. First install is the largest download; updates only fetch what changed.

  3. Press Play

    Pick your character name and class on the login scroll and enter the world. The launcher hands the game a one-time login token, so your password never goes into the game window.

What the launcher does

Small, boring, reliable

  • Signs you in against the account service and issues a one-time token for the game.
  • Installs and patches the game from the download server, verifying a SHA-256 checksum for every file.
  • Resumes interrupted downloads and repairs damaged files.
  • Shows server status and news, including the same notices as the news page.
  • Starts the game in its own window. Nothing is installed outside the folder you choose, except the launcher's own settings.

What your computer will say

Code-signing certificates are on the way. Until signing is live, your operating system cannot recognise the publisher and will warn you. That warning is expected for these builds. If the file you hold does not match the checksum below, do not run it.

Windows SmartScreen

You may see "Windows protected your PC". Choose More info, check that the file name is {{cfg.downloads.files.win}}, then choose Run anyway. Your browser may also ask you to confirm that you want to keep the download.

macOS Gatekeeper

macOS may say the app "cannot be opened because the developer cannot be verified". Open the disk image, then Control-click (or right-click) the launcher and choose Open, then Open again. If that option is missing, go to System Settings, Privacy & Security, scroll down and choose Open Anyway.

Linux

Mark the AppImage as executable, either in your file manager's properties or with chmod +x {{cfg.downloads.files.linux}}, then run it. If it does not start, install libfuse2.

Why trust it?

The launcher is served only from dl.swordandseal.com over HTTPS, publishes its SHA-256 here, and never asks for anything beyond your game account. Signing removes the warning; it does not change what the software does.

Verify your download

Check the SHA-256

Compare the hash your computer calculates with the one listed for your file above. They must match exactly.

Open PowerShell in your Downloads folder:

Get-FileHash .\{{cfg.downloads.files.win}} -Algorithm SHA256

Expected: published with each release

Open Terminal in your Downloads folder:

shasum -a 256 {{cfg.downloads.files.mac}}

Expected: published with each release

In a terminal in your Downloads folder:

sha256sum {{cfg.downloads.files.linux}}
