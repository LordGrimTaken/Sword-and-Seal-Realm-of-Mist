## Verdict
74 < 75: does NOT meet the ship threshold. No hard-gate failure and every category is at or above 50% (lowest: content 62%, desktop 60%, gameplay 67%), so the only blocker is the total. One point is within the grader's uncertainty band, but conservative banding was applied as instructed.

## Top 6 remaining fixes (est. points)
1. Gameplay/boss (+2-3): rebalance early combat (Lv1-2 bamboo spirits at 120 HP shouldn't kill a fresh sword in seconds; reduce aggro chain/leash pulls or lower mob damage 25%), add a telegraphed boss mechanic (ground ring wind-up already exists as rune ring; make slam dodgeable) and add a bot test that actually kills the Stone Guardian with 3 classes.
2. Visual (+2-3): replace flat plaza tile ground with ink-wash painted paving and stronger vignette; add layered grey-blue mountain silhouettes visible from the plaza/shrine; desaturate fox-hill red foliage into the locked palette; give characters brush-drawn faces instead of the cute dot faces.
3. Content (+1-2): add a 4th mob (e.g. river sprite at the pond or bat spirits on the shrine road), second NPC quest (Lantern Keeper Mei) and a loot/inventory panel so drops are not only chat lines.
4. Tech/testing (+1-2): fix the flaky respawn check in server/scripts/bots.ts (wait for the `death` event, then for st!=="dead" with hp>0 observed after the dead snapshot); remove committed client/audio-test and art-preview build outputs or move to a dev folder; gate `window.__jz` behind `?debug=1`.
5. Desktop (+1-2): build and attach a Windows NSIS/portable and macOS dmg in CI (or at least win-unpacked via electron-builder on a Windows runner), and make start-desktop bundle its own Electron so no global install is needed.
6. UI polish (+1): fix minimap/target-frame overlap at narrow widths, change the NPC "Type /talk" line to mention F, add a visible cooldown number on hotbar and a level-up banner (currently only a chat line + small pillar).
