# Monetization, Community & Product

1. **Jade-only cosmetics catalog with zero combat stats** — Stand up a cosmetics tab in the existing shop that sells only appearance items priced in jade, so the 6 gear slots and 4 rarities are never outclassed by a paid item and pay-to-win pressure stays out of Cloudmist Valley.
2. **Dye packs keyed to the exact palette tokens** — Sell one-time dyes that recolor procedural gear across ink, paper, vermilion, jade, gold, and mist, so every paid color maps to the documented palette and never shifts a stat.
3. **Brush-trail dodge VFX in jade** — Offer alternate dodge-roll trails (falling petals, ink splash, jade mist) that replace the `dodge` event's default streak while keeping the 15 Qi cost and 1.5s cooldown identical, so a paid roll is pure appearance.
4. **Vermilion seal-stamp nameplates** — Sell alternate nameplate seal motifs (vermilion, gold, jade) that frame the worn title from `EntityState.ttl`, turning the existing title system into a prestige sink without touching wallet coin or combat.
5. **Per-skill color retints for the three classes** — Sell cosmetic color variants (a gold Sword Qi Wave, a vermilion Thunder Talisman, a paper-white Spring Rain) so any of the 4-skills-per-class rotations can be visually customized without changing Qi cost or damage.
6. **Lantern, gourd, and pouch off-hand overlays** — Let players overlay the class off-hands with cosmetic gourds, brush-holders, and pouches in jade, giving the visible gear slots a vanity layer that never alters the summed `gear` stats.
7. **Expanded ink-brush emote set** — Sell an extended set of brush-stroke emotes (bow, meditate, cheer) drawn from the procedural emote strokes, so social expression becomes a premium sink with no effect on mob clears.
8. **Title recolor and character rename** — Charge jade to recolor an earned merit title or rename a character, converting the `prog` system's prestige into a repeat vanity spend while earned titles stay fully attainable in-game.
9. **Photosensitive-safe cosmetic preview** — Render every cosmetic's preview with the no-flash rule and let photosensitive-safe mode strip hit flashes, so a paid effect never breaks the accessibility guarantee while the player is deciding.
10. **High-contrast shop UI with ARIA and focus rings** — Build the cosmetics storefront on the paper-scroll panel with gold focus rings, ARIA labels, and colour-assist patterns, so the monetized surface meets the same accessibility bar as the rest of the client.
11. **Explicit "No stats" seal on every paid item** — Stamp each cosmetics entry with a paper-scroll "No stats" seal and hide any stat display, making the pay-to-win firewall visible and auditable inside the shop itself.
12. **Cosmetic loadouts in the settings export** — Persist a player's chosen cosmetics in the versioned `jz.settings.v1` object so vanity purchases survive between the Electron launcher and the browser client without re-applying.
13. **Season pass mapped to the daily board** — Add a seasonal track that advances by completing Fen's daily tasks (the `have/need` counters like `bamboo_purge`), so the pass reinforces the existing daily loop instead of adding a parallel grind.
14. **Free and paid pass lanes with no combat power** — Split the pass into a free lane (coin, Healing Tonics) and a jade-paid lane (vanity, titles, atlas pages), keeping every paid reward cosmetic or convenience so the pass stays pay-for-prestige, not pay-to-win.
15. **Season progress from Stone Guardian clears** — Grant pass progress for the Stone Guardian's 3-phase kill and daily boss clear, tying the paid track to the slice's hardest telegraphed content rather than trivial mob spam.
16. **Class-pictogram pass cosmetics** — Award a season's headline cosmetic as a class-specific seal emblem for Sword Cultivator, Talisman Master, and Physician, so each of the three roles gets a distinct paid reward.
17. **Merit seal and title as pass anchors** — Place a season-exclusive merit seal and worn title at pass milestones, reusing the existing `prog` / `EntityState.ttl` prestige pipeline for paid rewards without minting new currencies.
18. **Atlas page as a paid pass reward** — Offer a missed atlas page on the paid lane so the atlas completion loop can be caught up through the pass, giving the collections system a premium on-ramp.
19. **Jade-purchased pass levels capped by day** — Allow jade to unlock a pass level but cap level purchases to a catch-up pace, so a player cannot skip the entire season in a single transaction.
20. **Season progress persisted in node:sqlite** — Store pass progress server-side in the same node:sqlite that holds wallets and dailies, so a pass never resets across reconnects or between the Electron and browser clients.
21. **Season pass "no Qi advantage" rule** — Codify that no pass reward grants extra Qi pool, faster regen, or dodge-cooldown reduction, protecting the 100-point Qi / 10-per-second / 1.5s dodge balance from monetization drift.
22. **Pass rewards routed through the toast pipeline** — Route pass rewards through the existing `toast` event kinds (poi, ach, title, item) so paid unlocks surface with the same paper-stamp feedback as earned rewards.
23. **Stone Guardian clear-time board** — Record and rank fastest Stone Guardian clear times on a paper ledger at Fen's notice board, giving the boss fight a competitive goal without adding content.
24. **Class-filtered clear boards** — Split the Stone Guardian board by Sword Cultivator, Talisman Master, and Physician so a healer's clear is judged against other healers rather than ranged burst damage.
25. **Daily-board completion streak board** — Track consecutive daily-board completions and rank them, encouraging the existing daily loop with a persistence-based leaderboard instead of a raw score chase.
26. **Atlas completion percentage board** — Rank players by atlas pages discovered in Cloudmist Valley, turning the exploration/collections system into a visible, low-stakes leaderboard.
27. **Merit point board reusing `prog`** — Surface the existing merit points from the `prog` message as a zone-wide "Most Meritorious" board, making prestige its own competition with no coin or jade payout.
28. **No-reward leaderboards to avoid pay-to-win** — Keep every leaderboard cosmetic and title-only (a gold name on the board), so jade spenders cannot buy rank and the board stays a pure skill-and-prestige measure.
29. **Weekly leaderboard rollover with titles** — Rotate boards weekly and stamp top finishers with a temporary title, so competition has a timed reward that expires and reopens demand.
30. **Leaderboard UI as a paper scroll with high contrast** — Render every board on the paper-scroll panel with colour-assist patterns (diamond pips for rank, not colour alone) and ARIA rows, keeping the accessibility priority on competitive surfaces.
31. **Sect premium tier as a jade sink** — Offer a sect-wide premium tier (larger roster, custom banner, shared storage expansion) paid in jade by members, converting guild vanity into a shared premium spend with zero combat stats.
32. **Sect banner and seal cosmetics in the palette** — Sell sect banners and member seals drawn from the vermilion/jade/gold motifs so guild identity is a cosmetic purchase, never a buff.

41. **Sect persist-and-migrate in node:sqlite** — Store sect rosters, ranks, and banners in node:sqlite so a guild survives server restarts and a leader handoff is a single persisted field, not an in-memory loss.
